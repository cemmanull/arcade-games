Os elementos do HTML

Texto

Este é um parágrafo. O HTML ignora as quebras de linha que você escreve no arquivo: pode escrever tudo numa linha só ou quebrar como quiser, que o resultado é o mesmo. Quem decide onde o texto quebra é a largura da janela.

Dentro de um parágrafo dá para marcar trechos: strong para o que é importante, em para ênfase, code para código, mark para destacar, small para letra miúda, e um link para outra página.

Um link precisa do atributo href, que diz para onde ele vai. Pode ser um site inteiro, um arquivo ao lado (como a próxima lição) ou um ponto dentro da própria página (como este, que pula para os formulários).

Uma citação. Note que o navegador já a afasta das margens sozinho — cada tag vem com uma aparência de fábrica.

Agrupar coisas

<div> é uma caixa genérica, sem significado nenhum, usada só para agrupar. <span> é a versão para pedaços de texto dentro de uma linha.

Use as duas quando não houver uma tag com significado que sirva. Se houver, prefira a que tem significado:

  • <header> — o topo de uma página ou seção
  • <nav> — um bloco de navegação
  • <main> — o conteúdo principal (um por página)
  • <section> — uma seção temática
  • <article> — um conteúdo que faz sentido sozinho
  • <aside> — conteúdo lateral, secundário
  • <footer> — o rodapé
